HALO

Harness for Agent Lifecycle & Oversight. A vendor-neutral runtime that governs what your AI agents are allowed to do — a confidence gate, a default-deny tool registry, audit, human review, and a kill switch around every agent decision. Language-neutral protocol; Python and Java reference bindings.

The problem

An LLM agent that only answers is low-stakes. An agent that acts — refunds a payment, merges a PR, emails a customer — is not. The moment agents take real actions, every team hand-rolls the same governance layer: auto-apply only above a confidence bar (else send to a human); let an agent flag risk but never block; restrict each agent to an explicit tool allowlist; audit every decision with PII stripped; and stop everything without a deploy. HALO is that layer, built once — a normative, language-neutral protocol with reference bindings in Python and Java. It owns the execution contract, not your prompts or business logic.

How HALO compares

HALO is a governance / oversight layer, not another way to build or orchestrate agents — so it is complementary to the frameworks below. Build an agent with LangGraph, CrewAI, or a raw SDK and run it under HALO to get the gate, registry, audit, and kill switch.

What the harness owns

Typed envelope

One AgentInput in, one AgentOutput out — the boundary where controls apply.

Authority + decision

Static capability ceiling (OBSERVE…BLOCK) vs. dynamic outcome (ALLOW…DEFER).

Confidence gate

Centralized, non-disableable: confidence < 0.8 → autoEnforced=false → human review.

Tool registry

Default-deny, runtime-enforced allowlists. No wildcards. Violations are security events.

Orchestration

Pipeline, Fan-out, Supervisor+Workers (supervisor holds no tools), Debate.

Pluggable ports

LLM, ToolRegistry, Policy, Audit, HumanReview, Observability, Memory, KillSwitch.

The invocation, gated

AgentInput ──▶ [ tenant/user scope check ] ──▶ agent decision logic (LLM via LlmPort, tools via ToolRegistryPort) ──▶ [ confidence gate ] confidence < threshold ─▶ autoEnforced=false ─▶ HumanReviewPort otherwise ─▶ autoEnforced=true ──▶ [ audit (append-only, PII-redacted) + observability ] ──▶ AgentOutput { decision{ action, confidence, rationale, autoEnforced } }

Design invariants

  1. The gate is in the runtime, not the agent. No agent approves its own decision.
  2. Tools are default-deny. A tool not in an agent's allowlist is unreachable.
  3. No self-escalation. An agent cannot widen its own authority at runtime.
  4. Every decision is auditable. Append-only, PII-redacted; BLOCK/ALERT carry explanations.
  5. The core is framework-free. Adapters depend on the core; the core depends on nothing.

Status

Increment 0 shipped the normative protocol spec, the Agent Contract schema, and ADR-0001..0012. Increment 1 added the Python 3.11+ reference runtime in bindings/python/ — a framework-free core (envelope, gate, registry, harness), Supervisor+Workers, port Protocols with in-memory adapters, and a contract loader. Increment 2 ships the real bindings and consumers: a Java 21 binding (bindings/java/, com.suplab.agentharness) with a grid migration adapter; apex-sdlc running all seven of its SDLC phase agents on the harness (a runnable reference journey walks one project through every phase offline); and aether-grid routing all seven of its governance agents through the harness with a shared default-deny tool registry — the harness, not the agents, decides enforcement. Increment 3 completes the protocol in both languages: all four orchestration patterns (Pipeline, Fan-out, Debate/Consensus, and Supervisor+Workers with a governed planning turn) plus side-effect gating (T-5, §5.3, ADR-0011) — the harness refuses ungoverned write/external tool calls before they execute. Increment 4 adds production adapters (human-review SLA monitoring, durable file audit, cross-process kill switch, Memory/Policy, pluggable redaction, an OpenTelemetry exporter, and OpenAI-compatible + Anthropic LLM providers). Every binding maps 1:1 to the spec §9 conformance checklist (Python 121 · Java 80 tests). See progress.md.
